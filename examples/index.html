interstage

Import WGSL shaders into TypeScript as typed TypeGPU modules. A TypeScript 7.1 content mapper reads your .wgsl files, so tsc and your editor check every place where host code meets shader code.

interstage on npm Source on GitHub Set it up

One file, two languages

The shader stays plain WGSL. interstage turns each declaration into its TypeGPU counterpart: structs into schemas, each @group into a bind group layout, functions into typed functions and entry points into pipeline stages.

Because tsc reads the shader itself, there is nothing to generate and nothing to keep in sync. Rename a field in the shader and the TypeScript that writes it stops compiling.

Examples

Each one runs in your browser on WebGPU. Open the contract drawer on any of them to see the shader next to the declarations tsc emits for it.

  • Slime

    Hundreds of thousands of agents lay and follow trails in three competing species.

    Five entry points in one WGSL module: scatter, clear, step, diffuse and a full-screen draw. The sliders write the Params struct field by field.

  • Ink

    Stable fluids with vorticity confinement. Drag through the water to stir it.

    Nine passes share one bind group layout of eight storage buffers, and TypeScript checks the element type of every buffer bound to it.

  • Sculpture

    A gyroid lattice and three orbiting drops, raymarched with soft shadows.

    A single fragment shader driven by one uniform struct, Scene, which TypeScript fills in by name.

  • Atlas

    An endless topographic map. Drag to travel, scroll to zoom.

    The fragment shader is TypeScript and calls elevation() from atlas.wgsl, so a call with the wrong vector type fails to compile.

Set it up

  1. Install interstage next to TypeScript 7.1 and TypeGPU.

    pnpm add -D interstage typescript@beta
pnpm add typegpu

  2. Register the content mapper in tsconfig.json. validate is optional and needs the webgpu package (pnpm add -D webgpu).

    {
  "compilerOptions": { "skipLibCheck": true },
  "contentMappers": [
    { "package": "interstage", "extensions": [".wgsl"], "options": { "validate": true } }
  ]
}

  3. Let Vite load .wgsl files as modules.

    import interstage from 'interstage/vite'

export default defineConfig({ plugins: [interstage()] })

  4. Type-check with permission to run the mapper. In VS Code, the TypeScript 7 extension does the same in trusted workspaces.

    tsc --noEmit --runExternalCode
